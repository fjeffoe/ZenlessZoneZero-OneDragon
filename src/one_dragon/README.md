# OneDragon 核心框架

## 模块概述
OneDragon 是项目的核心框架模块，提供基础架构和通用功能支持，目标是实现"一条龙"式的代码复用体系。

## 目录结构
- `base/`: 基础类和抽象定义
- `devtools/`: 开发工具
- `envs/`: 环境配置
- `gui/`: 图形界面组件  
- `thread/`: 线程管理
- `utils/`: 工具函数
- `yolo/`: 图像识别集成

## 核心功能
1. **基础架构**:
   - 提供项目基础类和接口
   - 实现核心设计模式

2. **开发支持**:
   - 调试工具
   - 测试框架集成

3. **环境管理**:
   - 配置加载
   - 环境隔离

4. **多线程**:
   - 任务调度
   - 并发控制

## 设计目标
1. 高内聚低耦合的模块化设计
2. 支持灵活扩展
3. 提供统一的开发规范
4. 实现代码最大程度复用
